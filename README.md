# 🐍 Classic Snake Game - Python Turtle Graphics

An interactive implementation of the classic Snake Game using Python's standard `turtle` library.

## 🌟 Features
- Real-time keyboard navigation (`Up`, `Down`, `Left`, `Right`).
- Dynamic food spawning & tail growing mechanics.
- Live score and persistent High-Score tracking.
- Boundary and self-collision detection algorithms.

## 🚀 How to Run
1. Make sure you have Python installed.
2. Run the script:
   ```bash
   python snake_game.py
